4-target AWS engine

Your repo decides the architecture

STATIC / SPA

S3 + CloudFront

Vite, React, Vue, Astro. Private bucket fronted by CloudFront Origin Access Control.

DOCKER / API

ECR + ECS Fargate + ALB

Express, Fastify, FastAPI, long-running backends. Generates a hardened non-root Dockerfile if missing.

SERVERLESS

Lambda + API Gateway

Event-driven APIs. Packages the bundle and provisions an HTTP API v2 stage.

SSR

AWS Amplify

Next.js App Router and full-stack apps. Generates amplify.yml for the compute branch.

A deterministic analyzer reads package.json, Dockerfile, serverless.yml, next.config and requirements.txt before anything is deployed.

Trust & reliability

Zero-trust builds, self-healing deploys

Phase 7: Zero-trust sandbox

  • AWS_*, GITHUB_*, LD_PRELOAD and NODE_OPTIONS stripped from build environments
  • Symlink escape and path traversal guard before upload
  • Shell-injection filter, 100 MB repo limit, 20 live-deployment cost cap

Phase 8: Self-healing engine

  • Diagnoses empty output folders, missing lockfiles and port mismatches
  • Patches the configuration (for example outputDirectory to ".") and retries
  • Completes the deployment without manual debugging
